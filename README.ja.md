# 自動ネットワーク構成と状態報告ツール

GNS3VM環境上に構築した仮想Ciscoネットワークのラボを対象とした、Pythonによるネットワークの自動化プロジェクトを作成しました。

SSHを利用して複数のネットワークデバイスから設定情報を収集し、取得したデータを解析・照合することによって、ネットワーク内のデバイスやインターフェースの接続関係を把握し、ネットワークの仕組みを全体的にイメージすることが可能になります。

本プロジェクトでは、個々のコマンド出力を一つずつ見るのではなく、ネットワーク内のデバイスをグループとしてOSPF、CDP、VLAN、トランク、STP、インターフェース、EtherChannelから取得した情報を組み合わせ、表示します。デバイス間およびインターフェース間の接続関係を特定することによって、ネットワークの分析を効率よく行うことが可能です。

## プロジェクトの目的

- 複数のネットワークデバイスから設定情報を自動的に収集する
- ネットワークデバイスの状態を自動的に収集する
- Cisco IOSのコマンドの生データを解析し、利用できるデータ構造に整形する
- ネットワーク中の各デバイスから得たデータを照合し、ネットワーク内の接続関係を特定する
- デバイス単位だけでなく、ネットワーク全体の状態を把握する
- OSPF、VLAN、トランク、STP、EtherChannelなどの情報を関連付けて表示する

## 設計・流れ

各デバイスから生データの収集 → データの解析と整形 → データの照合 →　ネットワークの状態を構築  →　表示

### 1. 収集

各ネットワークデバイスへSSH接続し、必要なCisco IOSコマンドを実行し、出力データを収集。


例：
-　OSPFネイバー情報
-　インターフェース設定情報
-　CDPネイバー情報
-　STPの状態
-　EtherChannel設定

### 2. 解析

Cisco IOSのコマンドの生データの必要な情報を抽出し、利用できるデータ構造に整形。

例：Dict, List など

### 3. 照合

ネットワーク内のデバイスから得たデータを照合することによって、ネットワーク内の接続関係を特定。

例：
-　STP、EtherChannelなどの情報を照合することで、ローカル側とリモート側の接続関係を把握。
-　デバイスIDの特定
-　リモートIPアドレスの特定
-　ローカルインターフェースの特定

### 4. 表示

照合したOSPF、VLAN、STP、トランク、EtherChannel情報をデバイス単位で表示し、ネットワーク内での配置や役割を確認。

## Pythonモジュール

### `connection.py`

ネットワークデバイスへのSSH接続を確立し、接続済みのデバイスへIOSコマンドを送信。

### `inventory.py`

ネットワークデバイスのプロファイルを定義。

ログイン情報は環境変数から取得します。

### `collectors.py`

各デバイスからCisco IOSのコマンドを実行し、ネットワーク内の状態の生データを収集。

### `parsers.py`

Cisco IOSの生データを解析し、後続の処理で利用できるデータ構造に整形。

### `correlators.py`

各デバイスから得たデータを照合し、デバイス、インターフェース、VLAN、STP、OSPF、EtherChannelなどの接続関係を特定。

### `network_state.py`

ネットワーク全体から収集した情報を処理し、各デバイスのネットワーク状態を構築。

### `ospf.py`

照合したOSPFネイバーの接続関係を表示。

### `vlan.py`

VLAN、トランク、STP、およびVLANに関連するデバイス間の接続関係を表示。

### `ether.py`

EtherChannelのローカル側とリモート側の接続関係、およびVLAN/STPとの関係を表示。

### `main.py`

各モジュールを合わせ、ネットワーク全体の情報収集、処理、照合、表示を実行。

## 必要な環境

- Ubuntu Server

## 設定

ログイン情報は`.env`ファイルで管理。

```text
NETWORK_USERNAME=your_username
NETWORK_PASSWORD=your_password
```

`.env`はgitignoreを利用してGitリポジトリから除外。

## 実行方法

Python仮想環境を有効にした状態で、プロジェクトディレクトリから実行。

```bash
python3 main.py
```

プログラムは各ネットワークデバイスへSSH接続し、必要な情報を収集してからネットワーク状態を表示。

## ネットワーク関係の把握

本プロジェクトでは、一つのコマンド出力だけでは判断できないネットワーク関係を、ネットワーク中の各デバイスから得たデータを照合することで特定する。

### OSPF

OSPFネイバー情報とインターフェース情報を照合し、OSPFネイバーが使用しているIPアドレスとインターフェースを関連付け。

### CDPとトランク

CDPネイバー情報とトランクインターフェース情報を照合し、トランク接続のローカル側とリモート側の関係を特定。

### VLANとSTP

VLAN、トランク、STPの情報を照合し、VLANごとのルートブリッジ、STPポート状態、リモートデバイスとの接続関係を表示。

### EtherChannel

EtherChannelのメンバーポート、Port-channel、CDPネイバー情報を照合し、ローカル側のEtherChannelとリモート側のPort-channelの接続関係を特定。

## 出力例

```text
EtherChannel Relationships
Po1 (Gi0/1, Gi1/2) <----------> (Gi0/2, Gi1/2) Po1 (DS2)
```

従来のコマンド出力を一つずつ確認する手順では時間がかかり、また作業段階で確認ミスが起こりやすい作業を、複数のデバイスから取得した情報を照合することによって効率化し、ネットワークの接続関係を表示。

## ラボ環境

本プロジェクトはGNS3VM上に構築したCiscoネットワークラボを使用。

複数のルーター、ディストリビューションスイッチ、アクセススイッチを組み合わせ、OSPF、VLAN、トランク、STP、EtherChannelなどのネットワーク構成を再現。
